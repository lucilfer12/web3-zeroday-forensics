# Security Policy

This repository is a defensive research project.

Please do not submit:

- private keys, seed phrases, API credentials, or secrets
- weaponized exploit kits
- malware
- scripts targeting live contracts or production infrastructure
- destructive proof-of-concept transactions

Safe contributions include:

- source verification
- timeline corrections
- root-cause analysis
- invariant models
- patch observations
- safe unit tests against toy state machines
- provenance improvements
- taxonomy corrections

For a real-world disclosure, contact the affected project through its published security channel rather than using this repository as the disclosure mechanism.
